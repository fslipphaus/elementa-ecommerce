# ELEMENTA v4 — fidelização visual

Esta versão mantém todo o backend da v3 e refina apenas a camada visual para ficar mais próxima do mockup aprovado.

Principais ajustes:
- Hero editorial claro e espaçoso
- Hierarquia tipográfica premium
- Galeria das quatro fragrâncias com proporções mais naturais
- Caixas/velas sem alongamento via CSS
- Seção de benefícios mais discreta
- Grid de coleção com mais respiro
- Manifesto de marca entre coleção e história
- Seção institucional com proporção editorial
- Rodapé verde profundo
- Responsividade desktop/tablet/mobile preservada
- Carrinho, checkout, estoque, frete, admin, PostgreSQL, Mercado Pago e e-mail da v3 preservados
